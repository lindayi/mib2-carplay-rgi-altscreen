# README preview images

These figures show **this fork's host fixtures**, not an owner's vehicle or an
upstream demonstration car. All route/media/speed values are synthetic.
They contain no private firmware capture, real album cover or mascot-pack artwork.

| Figure | Inputs and treatment |
| --- | --- |
| `guidance.png` | `tests/route_labels_preview.c`: exit/roundabout GLES frames, cropped only around their content and enlarged 2x. The local distance/next-road footer and lanes remain visible. |
| `map-cards.png` | `map_cards/test.c`: the media/Trip frame and camera-first badge, cropped from their synthetic 1440x455 test surface. The geometric record-cover image is generated by `map_cards/test.sh`. |
| `controls.png` | A menu-path diagram plus the `tests/vc_panel_test.c` root-page fixture. The panel is isolated for readability; its position here is not an on-car placement measurement. |

`tools/render_readme_previews.py` composes the figures and adds visible host-preview
labels. It reads only the named `build/` fixture outputs; it does not read the
owner's pack, phone metadata, private directories or vehicle logs.

## Regenerate

The commands below assume an existing host GLES test image with C/C++ compilers,
EGL/GLES, Python/Pillow and DejaVu fonts. The project's local
`mib2-rgi-baseline-test` image has those dependencies.
For a starting image recipe, see
[`tools/route-label-test.Dockerfile`](../../tools/route-label-test.Dockerfile);
the chosen image must also provide the DejaVu font files used by the composer.

From Windows PowerShell:

```powershell
docker run --rm --mount 'type=bind,source=E:\Projects\mib2-carplay-rgi-altscreen,target=/src' -w /src mib2-rgi-baseline-test bash -c 'set -e; export PATH=/usr/bin:/bin; bash tests/route_labels_preview.sh; bash map_cards/test.sh; bash scripts/test_vc_panel.sh; python3 tools/render_readme_previews.py'
```

On another machine, adjust the bind-mount source and local image name. These are host tests and
documentation generation, not a QNX build or an SD deployment.
The composer refuses unexpected fixture dimensions/crops so changed rendering
gets a visual review instead of silently publishing a misleading picture.

Inspect all three generated PNGs before committing. Cropping/enlargement is for
documentation only: the figures do not reproduce the complete Audi compositor,
prove physical dial clearance or establish live input ownership.
